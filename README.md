# dayoff-form · 휴무신청서 작성

이케아 광명점(운창 로지텍) 배송 매니저 휴무(휴가) 신청서를 웹에서 채워 이미지(PNG)·PDF로 저장하는 앱입니다.

## 사용법
1. 성명, 휴무 날짜(당일 체크 시 하루), 사유, 긴급연락처를 입력합니다. 작성일은 오늘 날짜가 기본입니다.
2. **미리보기**로 출력 모양을 확인합니다.
3. **이미지(PNG) 저장** 또는 **PDF 저장** 후 출력해서 팀장님께 제출합니다.

- 성명·연락처는 각자 기기(브라우저)에만 기억되며 어디에도 전송되지 않습니다.
- 휴대폰에서 저장이 안 되면 미리보기 이미지를 길게 눌러 저장하세요.

## 구성
- `index.html` 한 파일 (양식 이미지 포함, 서버 없음)
- 바탕화면 바로가기(PWA): `manifest.webmanifest`, `sw.js`, 아이콘 png
- GitHub Pages: Settings → Pages → Branch `main` / `(root)`
